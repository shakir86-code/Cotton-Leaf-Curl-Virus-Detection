# Android App Plan

Planned app: Kotlin + Android Studio.

Features:
- Capture a cotton leaf photo or choose one from the gallery.
- Run the model on-device (TensorFlow Lite) or through an optional FastAPI service.
- Show `Healthy` or `Possible Cotton Leaf Curl Virus` with an uncertainty note.
- Display general prevention guidance and recommend consulting an agricultural expert.

Status: planning notes only; Android source code has not been implemented yet. Do not present the prediction as a confirmed diagnosis or provide unverified pesticide dosage instructions.
